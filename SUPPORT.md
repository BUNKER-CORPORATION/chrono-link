# Support

Chrono Link is proprietary pre-release research software. Support is available only to authorized
users under their applicable agreement.

For reproducible software defects, use the
[bug report form](https://github.com/BUNKER-CORPORATION/chrono-link/issues/new?template=bug_report.yml)
after removing recordings, credentials, serial identifiers, and other sensitive data. Use the
[feature request form](https://github.com/BUNKER-CORPORATION/chrono-link/issues/new?template=feature_request.yml)
for scoped product proposals.

Before filing, confirm the issue on CPython 3.11.9 with the committed lock and include the exact
commit, operating system, command, exit code, and sanitized output. The project does not provide
medical, clinical, electrode-placement, or person-connected hardware support through public issues.

Security and privacy reports must follow [SECURITY.md](SECURITY.md), not the issue tracker.
